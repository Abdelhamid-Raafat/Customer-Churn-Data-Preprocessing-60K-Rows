# Customer-Churn-Data-Preprocessing-60K-Rows
A data preprocessing project using a 60K-row customer churn dataset, preparing the data for machine learning.

📌 What This Project Covers
Data cleaning and validation
Duplicate and missing-value handling
Exploratory Data Analysis (EDA)
Outlier detection and capping
Categorical encoding
Feature scaling
Train/test splitting
Class imbalance handling using:
Random Oversampling
Random Undersampling
SMOTE
🛠️ Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
imbalanced-learn
