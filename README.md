# Customer Churn Data Preprocessing

A data preprocessing project using a 60K-row customer churn dataset, preparing the data for machine learning.

## What This Project Covers

- Data cleaning and validation
- Missing-value handling
- Exploratory Data Analysis (EDA)
- Outlier detection and capping
- Categorical encoding
- Feature scaling
- Train/test splitting
- Class imbalance handling using Random Over/Under Sampling and SMOTE

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- imbalanced-learn

## Workflow

Raw Data → Cleaning → EDA → Train/Test Split → Missing Values → Outliers → Encoding → Scaling → Class Balancing → ML-Ready Data

## Files

- `Customer_churn_data_preprocessing_60kRows.ipynb` — preprocessing notebook
- `customer_churn_preprocessing_problems_60k.csv` — dataset
